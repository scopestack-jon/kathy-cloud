```

RGB: 76, 175, 80
```
**Usage:**
- Extension icon background
- Primary buttons
- Badge backgrounds
- Panel headers
- Active state indicators

### Dark Green (Material Design Green 800)
```
#2E7D32
RGB: 46, 125, 50
```
**Usage:**
- Text on light green backgrounds

- Success message text
- Icons and borders on payment cards

### Light Green (Material Design Green 50)
```
#E8F5E9
```

**Usage:**

## Color Consistency

All green shades follow Material Design color system:
- **50**: #E8F5E9 (lightest)
- **500**: #4CAF50 (primary brand)
- **800**: #2E7D32 (darkest text)

This ensures:
- Consistent visual language
- Accessible contrast ratios (WCAG AA compliant)
- Professional, modern appearance
- Easy maintenance and scaling

## Usage Guidelines

### DO:
- ✅ Use `#4CAF50` for all primary brand elements
- ✅ Use `#2E7D32` for text on light backgrounds
- ✅ Use `#E8F5E9` for success state backgrounds
- ✅ Maintain contrast ratios for accessibility

### DON'T:
- ❌ Don't use `#48AF50` (typo, not part of palette)
- ❌ Don't mix custom greens with Material Design greens
- ❌ Don't use green for error states
- ❌ Don't reduce opacity on text (use lighter shades instead)
